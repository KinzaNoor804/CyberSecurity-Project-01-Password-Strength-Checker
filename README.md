# Password Strength Checker

## Project Description

This project checks the strength of a user's password based on common cybersecurity standards.

The program evaluates password length and the presence of:

* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

## Features

* Password strength analysis
* Weak, Medium, and Strong password detection
* Give suggestions if password is weak or medium
* User-friendly output
* Basic cybersecurity best practices

## Technologies Used

* Python 3
* VS Code

## How to Run

1. Open terminal.
2. Run:

```bash
python password_strength_checker.py
```

3. Enter a password when prompted.

## Sample Output

Password: Hello123

Strength: Medium

Password: Hello@123

Strength: Strong
